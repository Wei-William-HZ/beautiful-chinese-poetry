## 为什么值得一读

- **跨越 13 座城市** — 杭州、北京、南京、苏州、西安、洛阳……用诗词丈量中国
- **11 种词牌格式** — 鹊桥仙、蝶恋花、念奴娇、水调歌头、江城子……
- **每首诗配摄影图** — 32 张实景照片，图文并茂
- **诗词赏析** — 每首附深度赏析，解读典故、意象与哲学
- **电子诗集** — 打开即看，诗词竖排 + 米纸风格的中式美学

## 关于作者

**魏东坡**，杭州野生诗人，让中式美学走向世界。创作涵盖绝句、律诗、词牌、现代诗，兼涉诗词理论，以古典笔法书写当代情怀。

> 人生天地之间，如白驹之过隙，忽然而已。魏东坡生在这个时代，自然会留下魏东坡的文化印记，也曾在这世间走过。
