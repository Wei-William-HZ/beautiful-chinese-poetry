# 配图说明

## 如何添加配图

1. 将图片文件放入此目录（`images/`），建议使用 `.jpg` 或 `.png` 格式
2. 图片命名建议与诗题一致，如 `北平雪.jpg`、`西湖春行.jpg`
3. 在对应的诗词 Markdown 文件中，图片引用格式为：

```markdown
![北平雪](./images/北平雪.jpg)
```

## 推荐图片规格

- 宽度：1200px 以内（GitHub 显示友好）
- 格式：JPEG（实景照片）/ PNG（书法题字、透明背景）
- 单张大小：建议 2MB 以内

## 图片来源建议

- 个人拍摄的实景照片
- 书法题字扫描件
- 国画/水墨风格配图
- 古迹名胜摄影

## 已预留配图的诗词

每首诗词的 Markdown 文件中已预留图片占位符，格式为 `![诗题](./images/诗题.jpg)`。只需将对应图片放入本目录并确保文件名一致即可。
